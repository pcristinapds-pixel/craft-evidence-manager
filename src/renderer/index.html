Como gerar o token de API
  1. Abra a página de tokens da sua conta Atlassian (Conta Atlassian › Segurança › Tokens de API), com o mesmo e-mail do Jira.
  2. Clique em Criar token de API.
  3. Dê um nome, como Craft Evidence Manager, e escolha a validade (no máximo 1 ano).
  4. Clique em Criar e copie o token. Ele só aparece uma vez.
  5. Cole no campo Token de API e clique em Testar conexão.

O token é pessoal: dá ao app o mesmo acesso que você tem no Jira. Não compartilhe.
